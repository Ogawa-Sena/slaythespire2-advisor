### パッチの検知（F-06）に使えるもの
- `release_info.json` の `version`（例：`"v0.111.0"`）を読むのがいちばん簡単。

- 予備として、Steam の `buildid` も使える

## 2. カードの名前・効果テキスト（翻訳データ）

- `.pck` の中の `localization/<言語>/cards.json` に、**ふつうのJSONファイルとして**入っている
  - 日本語：`localization/jpn/cards.json`、英語：`localization/eng/cards.json`
  - 14言語分ある。レリック（`relics.json`）、ポーション（`potions.json`）、パワー（`powers.json`）なども同じ形
- 形式：`"カードID.title"`（名前）と `"カードID.description"`（効果）の組
  - 例：`"ABRASIVE.title": "棘纏い"`、`"ABRASIVE.description": "[gold]敏捷[/gold]{DexterityPower:diff()}を得る。…"`
  - 効果の中の数字は `{DexterityPower:diff()}` のような**穴あき**になっていて、数値そのものは入っていない
- `.pck` の中身の一覧は、先頭のヘッダーと目次を読めば取り出せる（暗号化はされていない）

### Spire Codex のデータと比べた結果
| 比べたこと | 結果 |
|---|---|
| ゲームの日本語名とDBの日本語名が違うカード | **1枚**：`PROTECTOR` → ゲームは「**守護者**」、Spire Codex は「プロテクター」。CLAUDE.md のとおりゲームを正とする |
| ゲームにあってDBにないカードID | 48個（`DEPRECATED_CARD` など。今は使われていないカードの名前が残っているものと思われる。要確認） |
| DBにあってゲームにないカードID | 1個（`SCARE`） |

## 3. カードの数値（コスト・ダメージなど）

- `.pck` の中に `src/Core/Models/Cards/Abrasive.cs` のような C# のファイルがあるが、**中身は空**（1バイト）
- 数値は `sts2.dll`（プログラム本体）の中にあると思われる
  - 取り出すには、C# のプログラムを読める形に戻すツール（逆コンパイラ。例：ILSpy）が必要
  - **逆コンパイルが利用規約上OKかは、まだ確認していない**
- 当面の案：数値は Spire Codex のデータ（`vars`、`damage`、`block` など）を使い、
  効果テキストの穴あき部分の名前（`DexterityPower` など）と Spire Codex の `vars` の名前が合うかで照合する

## 4. セーブデータ・ラン履歴

| 項目 | 内容 |
|---|---|
| 場所 | `%APPDATA%\SlayTheSpire2\steam\<SteamのID>\` の下 |
| Modなしのデータ | `profile1\saves\` |
| Modありのデータ | `modded\profile1\saves\`（Modを入れて遊ぶと、こちらに分けて保存される） |
| 形式 | すべて**ふつうのJSON**（テキストで読める） |

### 今のラン状態：`current_run.save`（F-04 に使える）
- キャラ（`character_id`）、アセンション（`ascension`）、今のAct（`current_act_index`）、
  デッキ（`deck`）、レリック（`relics`）、ポーション、ゴールド（`gold`）、HP が入っている
- マス（部屋）を進むたびに書き換わる
- **画面のOCRに頼らずに、ラン状態を正確に取れる**。OCRで読むのは「今出ているカード報酬・ショップの品物」だけで済む
- ただし、**今出ているカード報酬の候補はまだ入っていない**（取ったあとに履歴として書かれる）。
  候補を知るには、これまでどおり画面を読む必要がある
- 乱数の状態（`rng`）も入っているが、**使わない**（先の報酬を予測するのはこのツールの目的外）

### ラン履歴：`history\<番号>.run`（F-07・F-13 に使える）
- 1ラン＝1ファイル。調べたときは **147ラン** あった
- 中身：キャラ、アセンション、ゲームのバージョン（`build_id`）、勝ったか（`win`）、途中でやめたか（`was_abandoned`）、
  マスごとの記録（`map_point_history`）
- マスごとの記録には、**カード報酬で何が出て、どれを取ったか**（`card_choices` の `was_picked`）、
  ゴールド、HP、ポーションの選択などが入っている
- → 自分の統計の初期データに使える

## 5. 気をつけること：Mod ありのデータ

- Mod を入れて遊んだときのセーブ・ラン履歴は `modded` フォルダに分かれる。このツールは両方を読めるようにする
- Mod でキャラ・カードが追加された場合、それらは外部の統計にない
- 統計（F-07）には、**公式5キャラ・公式カードだけを使う**のが安全
- カードの名前・効果テキストは、ゲームファイルの公式の翻訳データを正とする
