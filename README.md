# StS2 Advisor（スレスパ2 判断アシスタント）

カードゲーム **Slay the Spire 2**（スレイ・ザ・スパイア2。略して「スレスパ2」）を遊んでいる間に、
「どのカードを取るか」「お店で何を買うか」のおすすめを、もう1枚のモニターに表示する個人用のツールです。

- カードを選ぶ画面が出ると、数秒で「どのカードを取るのがよいか（取らない選択を含む順位）」が出ます。
- お店の画面が出ると、「今持っているお金で買える、いちばん良い買い物の組み合わせ」が出ます。
- 少しあとに、AI が「なぜそのカードなのか」を一言で書き足します。

> **ゲームの操作は一切しません。** 画面を撮影して読むだけで、クリックやキー入力は送りません。
> ゲームを改造するもの（Mod）でもありません。

---

## ゲームを遊んだことがない人へ

### どんなゲームか

- 1人で遊ぶ、**カードを使って敵と戦うゲーム**です。Steam で早期アクセス版として出ています。
- 自分が持っているカードの束を **デッキ** と呼びます。戦いでは、毎ターン、デッキから数枚を引いて、攻撃や防御のカードを出して戦います。
- 最初のデッキは、ただ攻撃するだけ・ただ守るだけの、基本のカードがほとんどです。
  戦いに勝つたびに新しいカードを手に入れ、デッキを強くしながら、マップを先へ進んでいきます。
- 負けたらそこで終わりで、次はまた最初のデッキからやり直しです。この「最初から、負ける（または最後まで勝ち抜く）までの1回の挑戦」を **ラン** と呼びます。

### 遊ぶ人が悩む場面（このツールが手伝うところ）

**① カード報酬：戦いに勝ったあと、3枚のカードから1枚を選ぶ**

- 選んだカードがデッキに入ります。**どれも取らない（スキップ）** こともできます。
- 何でも取ればよいわけではありません。弱いカードを入れると、強いカードを引ける回数が減り、デッキが弱くなるからです。
- カードは数百種類あり、同じカードでも「今のデッキに合うかどうか」で価値が変わります。そのため、その場で決めるのが難しい場面です。

**② ショップ：戦いで貯めたお金（ゴールド）で買い物をする**

- 次の4種類が売られています。
  - **カード**：デッキに入れるカード
  - **レリック**：持っているだけで、ずっと効果がある道具
  - **ポーション**：1回だけ使える道具（持てる数に限りがある）
  - **カード削除**：デッキから弱いカードを1枚抜く
- お金は限られているので、「どの組み合わせで買うのがいちばん得か」を考える必要があります。

### このツールがおすすめを決める方法

次の2つを混ぜて、点数の高い順に並べます。

1. **統計（たくさんのプレイヤーの記録）**
   外部のサイト（Spire Codex）が集めた多くのランの記録から、「このカードを取ったランは、取らなかったランより、勝つ割合がどれだけ高いか」（**勝率の上がり幅**）を使います。
2. **今のデッキとの相性**
   自分のデッキに似たデッキで勝った人のうち、何%がそのカードを入れていたかを使います。
   デッキが少ないうち（序盤）は統計を重く見て、デッキが育ってきたら相性を重く見ます（統計：相性 ＝ 8：2 → 6：4）。

ショップでは、品物ごとの「勝率の上がり幅」を価値として、持っているお金で買える組み合わせを全部試し、価値の合計がいちばん大きいものを選びます。

### 用語集

| 用語 | 意味 |
|---|---|
| ラン | 最初から、負ける（または最後まで勝ち抜く）までの1回の挑戦 |
| デッキ | 自分が持っているカードの束。戦いではここからカードを引く |
| カード報酬 | 戦いに勝ったあとに出る「3枚から1枚選ぶ」画面 |
| スキップ | カード報酬で、どのカードも取らないこと |
| ショップ | マップの途中にあるお店。ゴールドで買い物ができる |
| ゴールド | ゲームの中のお金 |
| レリック | 持っているだけで効果が続く道具 |
| ポーション | 1回だけ使える道具 |
| カード削除 | ショップで、デッキからカードを1枚抜いてもらうこと |
| レアリティ | カードの珍しさ。コモン（よく出る）・アンコモン・レア（めったに出ない）の3段階 |
| 強化（カード名の後ろの「+」） | 効果を強くしたカード |
| 無色カード | どのキャラでも手に入るカード |
| キャラ | 遊ぶキャラクター。キャラごとに使えるカードが違う |
| アセンション | 難しさの段階（0〜10。数字が大きいほど難しい） |
| Act | ランの章。先の Act ほど敵が強い |
| デッキの型 | デッキの方向性。例：毒で少しずつ削る型。同じ型のカードを集めると強くなる |
| セーブファイル | ゲームが今のランの状態（キャラ・デッキ・お金など）を書き残すファイル。このツールは読むだけ |
| OCR | 画像に写っている文字を読み取るしくみ。このツールは Windows に最初から入っているものを使う |

## できること

| 場面 | 表示するもの |
|---|---|
| カード報酬 | 候補のカードとスキップの順位、総合点（統計＋相性）、同じ珍しさのカードの中で上位何%か、相性、そのカードが向いているデッキの型、AI の一言コメント |
| ショップ | おすすめの買い物の組み合わせ（カード・レリック・ポーション・カード削除）、品物ごとの価値、AI のコメント。買い物をしたら、残りのお金でおすすめを出し直す |
| 起動したとき | ゲームが更新されていれば、カードの名前・説明文・アイコンをゲームのファイルから取り直し、警告を出す |

やらないこと：マップの進み方・休憩所・イベントの判断、複数人で遊ぶモード、ゲームの自動操作。

## 必要なもの

- **Windows 11**（Windows 標準の OCR を使うため）。日本語の OCR が入っていること
- **モニター2枚**（ゲーム用と、表示ウィンドウ用。1枚でも動くが、表示ウィンドウがゲームに重なると読み取れない）
- **Slay the Spire 2**（Steam 版。表示言語は日本語）
- **Java 21** と **Maven 3.9**（Java のプログラムを組み立てて動かす道具）
- **Claude Code**（Anthropic 社の AI「Claude」をコマンドで使う道具）にログイン済みであること。カード名の読み取りと一言コメントに使う（Pro プランの範囲で動く）
  - `claude.exe` が標準の場所（winget で入れた場所）に無いときは、環境変数 `CLAUDE_PATH` に場所を書く
- インターネット接続（統計とデッキとの相性を、外部のサイトに問い合わせるため）

API キーなどの秘密情報は使いません。

## 最初の準備（データの取り込み）

カードの統計などはプログラムに入っていないので、最初に一度だけ取り込みます。プロジェクトのフォルダで、上から順に実行してください。

| 順番 | コマンド | 内容 | 時間の目安 |
|---|---|---|---|
| 1 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.ImportCardsMain` | カードの内容（Spire Codex） | 数十秒 |
| 2 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.SyncGameCardsMain` | カード名を、ゲームのファイルにある公式の日本語名に合わせる | 数秒 |
| 3 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.ImportStatsMain` | カードの統計（Spire Codex） | 約1分 |
| 4 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.ImportMetabotMain` | カードの評価（MetaBot.GG。2つ目の意見） | 約13分 |
| 5 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.ImportItemsMain` | レリック・ポーションの内容と統計、ショップの統計 | 約2分半 |
| 6 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.ExtractIconsMain` | レリック・ポーションの絵（アイコン）をゲームのファイルから取り出す（ショップで品物を見分けるため） | 数秒 |
| 7 | `mvn compile exec:java -Dexec.mainClass=sts2advisor.ImportRunHistoryMain` | 自分の過去のランの記録（表示用。監視の起動時にも自動で取り込む） | 数秒 |

- データは `data/sts2advisor.db`（SQLite というデータベースのファイル1つ）に保存されます。
- ゲームを Steam の標準以外の場所に入れているときは、2 と 6 の最後に `-Dexec.args="ゲームのフォルダ"` を付けます。
- **ゲームが更新されたら**：起動したときに自動で、カード名・説明文・アイコンをゲームのファイルから取り直し、表示ウィンドウに警告を出します。
  外部の統計は自動では取り直さないので、必要なら 1〜5 をもう一度実行します。
  出たばかりのバージョンで、カードの内容だけ取り込み直すときは次を使います（統計は前のバージョンのまま）。
  `mvn compile exec:java -Dexec.mainClass=sts2advisor.ImportPatchCardsMain -Dexec.args="v0.113.0"`

## 起動方法

1. ゲームを起動します（どちらのモニターでもかまいません）。
2. プロジェクトのフォルダで、次を実行します。

```
mvn -q compile exec:java -Dexec.mainClass=sts2advisor.WatchScreenMain
```

- ゲームのあるモニターを自動で探して撮影し、**表示ウィンドウはもう一方のモニターの右上** に開きます。
- 遊んでいる途中でゲームを別のモニターに移しても、5秒以内に追いかけます。
- 止めるときは、表示ウィンドウを閉じるか、実行している画面で Ctrl + C を押します。
- モニターを自分で決めたいときは、`-Dexec.args="ゲームのモニター番号 表示ウィンドウのモニター番号"` を付けます（例：`"0 1"`）。

## 表示ウィンドウの見方（カード報酬のとき）

| 場所 | 表示されるもの |
|---|---|
| 一番上 | 画面の種類と時刻。読み取りの間は「カード報酬を読み取り中…」 |
| 赤い文字 | 警告（ゲームの更新を見つけた、カードの説明文がデータと違うかもしれない など） |
| 見出し | キャラ・アセンション（難しさ）・Act（章）・デッキの枚数・統計と相性の割合（序盤は 8：2、デッキが14枚以上なら 6：4）、今のデッキの型、青い文字で AI の見立て |
| 各行（1位は黄色） | 下の表を参照 |
| 一番下 | データの出典へのリンク（Spire Codex・MetaBot.GG） |

各行に出るもの：

| 表示 | 意味 |
|---|---|
| 「1位 ○○」 | 順位とカード名。カード名の後ろの「+」は強化済みのカード |
| 総合 ○点（統計 ○点＋相性） | 順位に使った点数（0〜100。高いほどおすすめ）と、相性を混ぜる前の統計だけの点数 |
| コモンの中で上位 ○% | 同じ珍しさのカードの中で、統計が上から何%か（小さいほど良い） |
| 勝率の上がり幅 | そのカードを取ったランの勝率が、取らなかったランより何ポイント高いか（マイナスは低い） |
| Metabot 上位 ○% | 別のサイト（MetaBot.GG）での評価。2つ目の意見として並べるだけで、順位には混ぜない |
| 自分：出た ○回・取った ○回 | 自分の過去のランで、そのカードが何回出て、何回取ったか（表示するだけ） |
| 緑の文字 | 今のデッキとの相性（似たデッキで勝った人の何%が採用したか）と、そのカードが向いているデッキの型 |
| 青い文字 | AI の一言コメント |
| 「スキップ」の行 | 取らない方がよい基準。これより下のカードは「取らない方がよい」という意味 |

使い方のこつ：

- マウスをカードに乗せたままだと、説明の枠で隣のカード名が隠れて、読み直しが入ります。早く出したいときは、マウスをカードから外してください。
- スキップの位置は、デッキの枚数で変わります。デッキが少ないうちは多少弱いカードでも取った方がよいのでスキップは下の方、デッキが多くなると弱いカードは取らない方がよいのでスキップが上がります
  （15枚未満は下位20%、15〜19枚は下位40%、20枚以上は下位55% のカードより、スキップを上にする）。

## しくみ

```
1秒ごとにゲームの画面を撮影 → 画面の種類を判定（Windows の OCR で文字を読む）
  ├ カード報酬 → カード名の部分を切り出して AI が読む → セーブファイルから今のデッキを読む
  │             → 統計と相性で順位をつけて表示 → AI の一言コメントを書き足す
  ├ ショップ   → 品物の場所・値段・所持金を読み、レリック・ポーションは絵（アイコン）で見分ける
  │             → 所持金で買える最適な組み合わせを表示 → AI のコメントを書き足す
  └ その他     → 何もしない
どの場合も、撮影した画面・読み取り結果・順位とコメントを data/logs に保存する（あとで精度を確かめるため）
```

## 確認用の入口

ゲームを起動しなくても、保存した画像などで動きを確かめられます。

| コマンドの mainClass | 内容 |
|---|---|
| `sts2advisor.ClassifyImagesMain` | フォルダの画像の、画面の種類を判定する（例：`-Dexec.args="samples"`） |
| `sts2advisor.ReadCardRewardMain` | 画像からカード報酬のカード名を読む |
| `sts2advisor.ReadShopMain` | 画像からショップの品物・値段を読み、おすすめを出す |
| `sts2advisor.RankCardsMain` | キャラ・アセンション・デッキの枚数・カード名を指定して順位を出す（例：`-Dexec.args="DEFECT 1 12 氷河 スクレイプ 大騒ぎ"`） |
| `sts2advisor.ShowRunStateMain` | セーブファイルから今のランの状態を表示する |

## フォルダの構成

| 場所 | 内容 |
|---|---|
| `src/main/java/sts2advisor/` | プログラム（Java）。ファイルごとに役割を日本語のコメントで書いてある |
| `scripts/winocr_server.ps1` | Windows の OCR を呼び出すための PowerShell のスクリプト |
| `docs/` | 調査の結果（外部データ・ゲームのファイル・画面の読み取り）と、提出用のまとめ（submission_summary.xlsx） |
| `samples/` | 確認用の画像（※ゲームの画面なので共有しない） |
| `data/` | データベース・アイコン・判断ログ（自分の PC で作るもの。共有しない） |
| `CLAUDE.md` | AI（Claude Code）に与えた前提・ルール・決めたこと・作業の記録 |

## データの出典と利用規約

| 出典 | 使い方 | 規約 |
|---|---|---|
| [Spire Codex](https://spire-codex.com) | カードの内容・統計、デッキとの相性（pick-coach） | 公開 API の利用が規約で認められている。1分15回の制限を守る |
| [MetaBot.GG](https://metabot.gg) | カードの評価（2つ目の意見） | 公開 MCP サーバーの利用が認められている。条件：出典リンクを表示する（表示ウィンドウに表示） |
| ゲームのファイル・セーブファイル | カード名・説明文・アイコン、今のランの状態、過去のランの記録 | 自分の PC のファイルを読むだけ（書き換えない） |

Untapped.gg・OP.GG は規約で自動取得が禁止されているため使っていません。
Spire Codex に送るのはカードとレリックの ID だけで、個人の情報は送りません。

## 注意

- ゲームの画面の画像・判断ログ・ゲームから取り出したアイコン・データベースは、`.gitignore` で共有しないようにしています。
- 統計はプレイヤー全体のものです。順位は目安として使い、最後は自分で決めてください。
- ゲームが出たばかりのバージョンのときは、統計が前のバージョンのままのことがあります（表示ウィンドウに警告が出ます）。
